# Product

## Purpose

This product is v2 of the lnaguage learner app described in PRODUCT.md. It adds upgrades to that MVP version.

## Users

Individuals learning a new language.

## Version 2

Users must be able to do everything in version 1, plus:
Several users must be able to access the app at the same time from different devices.
Each user must be able to set their own categories - so for eg the same card might be 'don't know' for one user and 'know well' for another.
The total pool of cards can be the same for all users - there is no need to create separate sets of cards for each user.
Only the app owner should be allowed to delete a card (to prevent another user deleting cards the owner wants there, or worse, deleting everything accidentally).
Version 1 should remain live and useable. In other words, better that this builds a separate v2, rather than overwriting v1, as v1 is being used.
Each user should be able to select view orders based on how recently they viewed a card.

## Not in version 2

Audio or sounds.
Pictures.
Public use - this is a private app for a group of friends to share.
Complexities like APIs or runtime AI.

## Constraints

I am the product owner and am not a software engineer.
The product should be simple to maintain using AI coding tools.
Prefer mainstream, well-supported technologies.
Avoid unnecessary infrastructure and dependencies.
