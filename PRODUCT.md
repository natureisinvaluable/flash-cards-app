# Product

## Purpose

This product is a simple user interface for a lnaguage learner to create a written flashcard where one side is English, the other side is in the language they are learning.

## Users

Individuals learning a new language.

## Version 1

Users must be able to:
Create and save flashcards.
Correct mistakes, and delete flashcards that are no longer needed.
Use colour (eg differently coloured text) as a memory aid on a card.
Organise flashcards into simple categories based on how well they know the card - eg know well, know a little, don't know.
Change the category of a flashcard with a simple click.
View flashcards to test their knowledge.
Search for a flashcard using either the English or other language.
Shuffle the cards within a category to avoid getting too used to specific order.

## Not in version 1

Audio or sounds.
Pictures.
Auth.
Public use - this is a private app.
Complexities like APIs or runtime AI.

## Constraints

I am the product owner and am not a software engineer.
The product should be simple to maintain using AI coding tools.
Prefer mainstream, well-supported technologies.
Avoid unnecessary infrastructure and dependencies.
